# 蔡Sindy — 房仲客戶管理系統

一套給房仲使用的客戶、買方、成交與物件管理系統。前端 React + Vite，後端使用 Supabase，資料即時同步、可多人共用。

---

## 快速開始

### 1. 安裝套件

```bash
npm install
```

### 2. 設定環境變數

在專案根目錄建立 `.env.local`：

```env
VITE_SUPABASE_URL=你的_Supabase_專案網址
VITE_SUPABASE_PUBLISHABLE_KEY=你的_Supabase_anon_public_key
```

> 兩個值可在 Supabase 後台 **Project Settings → API** 取得。

### 3. 啟動開發伺服器

```bash
npm run dev
```

瀏覽器開啟終端機顯示的網址（預設 `http://localhost:5173`）。

### 其他指令

| 指令 | 說明 |
|------|------|
| `npm run dev` | 本機開發（含熱更新） |
| `npm run build` | 打包正式版到 `dist/` |
| `npm run preview` | 預覽打包結果 |
| `npm run lint` | ESLint 檢查 |

## 功能介紹

系統頂端有四個分頁：

### 📋 追蹤線
管理追蹤中的客戶。每位客戶底下可展開**物件子列**，記錄此客戶看過/負責的物件。

- **追/募**：下拉切換「追蹤 / 募集」
- **客戶姓名**：點擊可開啟買方資料彈窗（依姓名連結買方）
- **客戶電話**：若有同名買方，自動帶入買方電話
- **維護紀錄**：點擊展開，可新增維護紀錄
- **下次計劃 / 備註**：點擊文字即可直接編輯
- **物件子列**：
  - **同業/自售**：下拉即時切換
  - **物件帶看日**：選日期
  - **業務紀錄**：點擊開啟彈窗，可新增同業網址與備註
  - 展開後可看到總價、格局、社區、交易紀錄等明細
- **+ 新增物件**：輸入物件編號可自動帶入已存在的物件資訊
- **搜尋框**：依「社區 / 地址 / 總價」搜尋（從開頭比對）
- 列表依**最後修改日**由新到舊排序，剛改過的客戶會排在最上面

### 👤 買方
管理買方名單與需求。

- 欄位：人員、姓名、電話、生日、戶籍地、通訊地、預算、期望格局、期望地區
- **編輯**按鈕：進入編輯模式，可改多個欄位後一次儲存
- **備註**：點擊文字直接編輯
- **已看過物件**：點擊展開該買方關聯的物件卡片

### 🤝 成交客戶
管理已成交的客戶。

- 欄位：選項（買/賣/租）、姓名、電話、生日、戶籍地、通訊地、成交地址、社區、備註
- 若姓名與買方相同，**電話、生日、戶籍地、通訊地會自動帶入買方資料**
- **編輯**按鈕可修改生日、成交地址、社區
- 姓名、選項、備註可直接點擊編輯

### 🏠 物件管理
所有物件的主檔。

- 欄位：物件編號、買/租/賣、地址、總價/月租金、格局、樓高、社區、用途、坪數、物件類型、車位、交易紀錄、備註
- 物件編號依交易類型自動產生（A=買、B=租、C=賣）
- **買/租/賣**：下拉即時切換；選「租」時金額不顯示「萬」
- **編輯**按鈕可修改地址、總價、格局
- 交易紀錄、備註點擊文字直接編輯
- **在此修改的物件資訊，會即時同步到「追蹤線」中所有引用該物件的客戶子列**

## 部署

本專案為純前端 SPA，後端託管於 Supabase，**不需自建伺服器**。推薦使用 **Vercel**：

1. 將專案推上 GitHub
2. Vercel 匯入該 repo（會自動偵測 Vite）
3. 在 Vercel 專案設定加入環境變數 `VITE_SUPABASE_URL`、`VITE_SUPABASE_PUBLISHABLE_KEY`
4. Deploy
